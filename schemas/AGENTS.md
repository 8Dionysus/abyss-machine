# schemas Route

`schemas/` contains public data-shape anchors for bootstrap, policies, and
host evidence. Keep v1 schemas permissive until implementation data settles.

The active-organ C18/C19 and ER6 schemas are deliberate strict security
boundaries. Do not relax their unknown-field, path-disclosure, root-mutation,
effect-authority, live-execution, or global-completion guards to admit a
fixture.

Never paste live private records as schema examples.
