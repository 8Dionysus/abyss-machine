# mechanics Route

`mechanics/` owns durable host-machine movement packages. Add or edit a package
when the work has a recurring trigger, clear owner boundary, inputs, outputs,
and validation route.

Every package keeps `AGENTS.md` for the owner delta and `README.md` for the
human mechanic card. Add `DIRECTION.md`, `PROVENANCE.md`, `PARTS.md`,
`ROADMAP.md`, or `LANDING_LOG.md` only while it carries package-specific
information.

Create `docs/` or `parts/` only for real package content. When either directory
exists, keep its README as a local human index; do not preserve an otherwise
empty directory with a placeholder README.

Do not use mechanics as a dumping ground for generic notes.
