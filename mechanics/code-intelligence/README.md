# Code Intelligence Mechanic

## Mechanic card

This package gives the host layer one aggregate, content-addressed provider
plane: Universal Ctags; exact Node runtimes for Tree-sitter, SCIP, and LSP;
and adjacent Semgrep, Syft, in-toto, and MarkItDown routes. The aggregate is a
dedicated artifact class so its registry latest cannot replace unrelated host
runtime bundles.

### Trigger

Prepare, inspect, admit, install, or exercise the exact code-intelligence
provider artifact.

### abyss-machine owns

The content-addressed provider archive shape, artifact manifest and sidecars,
source and installed identity, storage/resource preflight, registry/trust-gate
consumer check, atomic runtime placement, and facts-only version/symbol probe.

### Stronger owner split

`abyss-stack` owns provider lifecycle, LIVE sessions, and runtime meaning.
`aoa-kag` owns normalized observation consumption. `aoa-evals` owns semantic
proof and eval verdicts. The machine layer does not mint the G58 trust anchor or
the authenticated stack evidence gate.

### Inputs

An exact source ref, the pinned Ctags source revision, npm and Python locks,
the pinned Syft release identity, the dedicated bundle manifest, existing
artifact trust roots/credentials, owner registry evidence, and bounded host
storage/resource facts.

### Outputs

Unsigned candidate archives or a fully sidecar-bound aggregate bundle posture,
a fail-closed trust/admission decision, identity-bound Ctags, Node, and
adjacent runtime installations, and bounded provider observations. Every
output names its claim limits.

### Must not claim

Build output is not a signature, registry promotion, trust-gate allow,
installation, deployment, semantic proof, eval verdict, landing, or owner
acceptance. G42 INDEXED output is not accepted input without a later exact
master disposition.

### Validation

Run the focused code-intelligence tests, artifact manifest/policy validators,
the deterministic archive test, and the owner trust/admission route. Before a
durable install, run storage write-preflight and changes preflight. Execute the
fixed continuation validators last.

### Next route

After MACHINE admission and runtime evidence exist, hand the exact provider
identity to `abyss-stack` for its signed G58 evidence gate and LIVE lifecycle;
then route semantic usefulness to `aoa-evals`.
